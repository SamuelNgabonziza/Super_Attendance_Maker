# Super Attendance Maker 📋

An Android app that makes attendance-taking fast, accurate, and paperless for companies and institutions.

Instead of paper sign-in sheets or manual spreadsheets, **Super Attendance Maker** lets organizations record employee/worker attendance directly on a phone cutting down time wastage and reducing human error in attendance handling.


## ✨ Features

- 📱 Simple, mobile-first attendance recording
- 🏢 Built for companies and institutions managing multiple employees/workers
- ⏱️ Reduces time wasted on manual attendance processes
- ✅ Minimizes errors common with paper-based or manual tracking
- 📦 Ready-to-install APK.





## 📥 Installation

### Option 1: Install the APK directly (for users)
1. Go to the [Releases](../../releases) page of this repository
2. Download the latest `attend_ease.apk`
3. On your Android phone, open the downloaded file and allow installation from unknown sources if prompted
4. Open the app and get started

### Option 2: Build from source (for developers)
```bash
git clone https://github.com/SamuelNgabonziza/Super_Attendance_Maker.git
cd Super_Attendance_Maker
```

## 🛠️ Tech Stack

- **Platform:** Android
- **Build system:** Gradle (Kotlin DSL)
- **Language:** Kotlin
